What we changed

Faster to load. Nothing else changed.

The design, content, booking flow and animations stayed the same. The work was in how the page is delivered to a phone.

  • Mobile performance audit. Traced what was delaying the first screen on a phone before changing anything — the first text on screen was waiting on web fonts loaded from Google, and phones were downloading much larger images than they display.
  • Image optimisation. Every photo on the page now comes in several sizes, as AVIF with a WebP fallback, so each phone downloads only what it needs. On small screens the hero uses a portrait crop instead of the full landscape photo.
  • Self-hosted fonts. The site's fonts are now served from lashlair.com itself instead of Google Fonts, removing two extra connections, and the fonts the first screen needs are requested first.
  • Smaller stylesheet and script. Production CSS and JavaScript are minified; the script still loads without blocking the page, and the booking code is unchanged.
  • Small-screen fix. Corrected buttons and a grid that overflowed the screen on the narrowest phones.
  • Design checked, then retested. The page was compared at nine widths from 320 to 1440 pixels to confirm nothing visible changed, the booking form was tested, and the live site was re-run in PageSpeed Insights.
